# {{DOMAIN}}

Статичний сайт на Cloudflare Workers (static assets). Деплой — Workers Builds на пуш у `main`.

## Шаблон

Плейсхолдери, які адмінка PBN Manager замінює при створенні сайту:

- `{{DOMAIN}}` — домен (example.com)
- `{{SITE_TITLE}}` — назва сайту
- `{{WORKER_NAME}}` — назва воркера

Файли сайту — у `public/`.
